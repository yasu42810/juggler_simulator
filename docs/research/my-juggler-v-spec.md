# 調査メモ: マイジャグラーV スペック値

- 調査日: 2026-10-25（2回目の調査で公式情報とぶどうの出典比較を追加）
- 目的: 代表機種（初版対象）の確率データを、出典・データ種別付きで確定させる
- 結論:
  - **ボーナス確率・機械割**: 複数の第三者サイトに掲載された V のメーカー公表値を採用。北電子公式の後継機（マイジャグラーⅥ）のページの値とも全設定で一致することを確認した（V の値の直接の出典ではなく、裏付けとして記録）。
  - **ぶどう確率**: 公式の公表はない。7つの出典を比べ、最も広く使われ、比較した出典の設定ごとの中央値とも一致するガリぞう調べの値を**実用上の採用値**とした（§4）。真の値が確定したわけではない。

### 4.2 採用値と理由

**採用: 1/5.90, 1/5.85, 1/5.80, 1/5.78, 1/5.76, 1/5.66（A: ガリぞう調べ）**

1. 最も多くのサイト（Pタウン、必勝本、juggler7、スロットHacks）が掲載しており、利用者が他のツールと見比べたときに食い違いにくい。
2. A, C, D, E, F の設定ごとの中央値が、A と全設定で一致する。ただし C・D・G は同じ系統のシミュレーターアプリから算出した可能性があり、E は出どころ不明なので、**互いに独立した裏付けとは言い切れない**。中央値の一致は「A が他の値から外れていない」ことの確認にとどめる。
3. 設定6の値は A, C, D, E, G で 1/5.65〜1/5.67 にまとまっている。
4. B（逆算値）は中央値の計算から外した。設定3〜5が同じ値になっており、他の出典と性質（機械割からの逆算）が違い、逆算の前提も書かれていないため。B の値で計算した場合の差は §4.3 の感度に含めている。

### 4.3 不確かさ

- 各設定300万Gのシミュレーションの場合、1/5.8 付近でのぶどう確率の標準誤差は 1/x の x で約 0.0073（95% の幅で約 ±0.014）。出典間の差（0.03〜0.08）はそれより大きいので、乱数のばらつきだけでは説明しにくい。数え方の条件（内部中の扱いなど）や算出方法の違いが考えられるが、**原因は確認できていない**。どの出典も条件を明記していない（→ Q-15 の計測規約は、条件が分かり次第見直す）。
- 出典を変えたときの事後確率の差（内部設計 §4.3 の式、均等事前）:

| 入力 | 採用値 A での設定4以上 | 他の出典での範囲 | 設定6の範囲 |
|---|---|---|---|
| N=3000, B=12, R=11, n=1500, g=265 | 64.4% | 63.1〜66.2% | 18.9〜20.1% |
| N=8000, B=33, R=35, n=8000, g=1400（高設定寄り） | 95.9% | 95.7〜96.6% | 44.9〜50.7% |
| N=8000, B=30, R=22, n=8000, g=1355（低設定寄り） | 17.2% | 15.2〜22.0% | 0.2〜1.0% |

- 「設定4以上」のような粗い見方では差は数ポイント、「設定5か6か」のような細かい見方では差が大きくなる。画面ではぶどうが解析値であることを示し、ぶどうを計算から外せるようにする（要件 FR-19）。
