# 調査メモ: ホールの設定配分（事前分布の根拠）

- 調査日: 2026-10-25
- 目的: 依頼者の要望「設定6は入りづらいので、事前分布に傾斜をもたせる。一般的な分布を Web 記事などから求める」に応え、既定の事前分布を決める。
- 結論: 既定の事前分布を **「標準（低設定中心の想定）」= 設定1〜6: 31.8 / 31.6 / 23.5 / 8.1 / 3.6 / 1.4 %** とする。あわせて「高設定やや多め（イベント日の想定）」「均等」を選べるようにする。
- 位置づけ: 全国の店の実態を測った値ではない。**Web の情報を参考に決めた「仮定」**（シナリオとしての事前分布）であり、画面でもそう説明する。

## 2. 読み取れること

- **設定6はどの情報でも 1〜2% 前後**。設定5〜6 を合わせても 4〜7% 程度。依頼者の「設定6は入りづらい」という感覚と一致する。
- 設定4〜6 の合計は、実データ（P1, P2）で約 18%、ブログの推定（P3, P5）で 9〜13%。
- 設定1〜3 の内訳は、情報によって大きく違う。
  - 実データ（P1, P2）では設定2・3 が中心で、設定1 は約 11%。ただし**導入直後の2週間**なので、新台の時期として高めに使われている可能性がある。
  - ブログの推定（P3）では設定1 が半分以上。ただし根拠は書かれていない。
- どの情報も、性質（時期・機種・集計方法）が違い、そのまま平均して「実態」を推定できる統計的な根拠はない。

## 3. 「標準（低設定中心の想定）」の決め方

情報の性質が違うため、**統計的な推定ではなく、次の決まった手順で作った仮定**として扱う。

1. 各情報を合計100%に直す。範囲で書かれているもの（P3）は中央値を使う。P5 の「設定6 1未満」は 0.7% とみなす（仮定）。
2. **設定4〜6**: 実データ（P1・P2 の平均）、P3、P5 の3つを平均する → 設定4 = 8.1%、設定5 = 3.6%、設定6 = 1.4%（合計 13.1%）。
3. **設定1〜3**: 残りの 86.9% を、「P1・P2 の平均」と「P3」の、設定1〜3 の中の比率を平均して分ける → 31.8 / 31.6 / 23.5%。（P5 は設定1〜3 の内訳がないので使えない）
4. 小数第1位に丸める（合計 100.0%）。

**参考計算**: この配分で台数を均等に重み付けした機械割の平均は約 98.9%。等価交換で、全台の稼働が同じで、公表値どおりに出ると仮定すると、ホールの粗利は1枚あたり約 20銭 で、P6 の推奨粗利（15〜20銭）と同じくらいになる。ただし、実際の営業では高設定ほどよく回る・公表値と実績がずれる・交換率が違うなどで変わるため、**この一致は配分が正しいことの裏付けにはならない**。大きく外れていないことの目安にとどめる。

## 5. 事前分布による結果の違い（マイジャグラーV）

| 入力 | 均等 | 標準（既定） | 高設定やや多め |
|---|---|---|---|
| N=3000, B=12, R=11 | 設定4以上 61.4% / 設定6 17.7% | 20.5% / 1.8% | 38.4% / 5.4% |
| 上記 + n=1500, ぶどう 265 | 64.4% / 19.4% | 22.6% / 2.1% | 42.0% / 6.2% |
| N=6000, B=24, R=25 | 85.8% / 31.9% | 48.2% / 6.2% | 72.9% / 14.4% |
| N=8000, B=33, R=35, n=8000, ぶどう 1400（高設定寄り） | 95.9% / 46.1% | 76.1% / 15.2% | 91.8% / 26.3% |
| N=8000, B=30, R=22, n=8000, ぶどう 1355（低設定寄り） | 17.2% / 0.3% | 4.5% / 0.0% | 8.6% / 0.1% |

- **事前分布の影響は大きい**。特に「設定6かどうか」は、1日分のデータでも事前分布で結果が何倍も変わる。
- 依頼者の「多少の傾斜」に対して、`standard` は設定1と設定6の比が約23倍で、強めに効く。緩めたい場合は、`standard` と均等を混ぜる（例: 半々）ことで傾斜の強さを調整できる。ただし混ぜる割合も仮定である（→ 未決事項 Q-22）。
- 画面では、選んだ事前分布での結果に加えて、**比較として**均等の場合の値を小さく並べる（均等が正しいという意味ではない）。

## 6. 注意点

- 店・日・機種・地域によって配分は大きく違う。ここで決めたのは「目安となる想定」であり、特定の店の配分でも全国平均でもない。
- 実データ（P1, P2）は導入直後の2週間分で、通常の時期より高い設定が多めの可能性がある。ブログ（P3〜P5）は根拠が示されていない。
- 店ごとの配分の推定（要件 FR-32, Phase 4）ができれば、この既定値はその店の推定値に置き換わる。
- 数値は事実として引用し、各記事の文章・表・画像は転載しない。
