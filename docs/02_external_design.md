## 1. システム構成（利用者から見た形）

```
 ┌───────────── スマホのブラウザ ─────────────┐
 │  Webアプリ（HTML/JS/CSS, 静的ファイルのみ）   │
 │   ├ 機種データ（JSON, アプリに同梱）          │
 │   ├ 計算はすべて端末内で実行                  │
 │   └ 入力値は localStorage に保存              │
 └──────────────▲──────────────────────────────┘
                │ 初回のみ取得（以後は Service Worker のキャッシュで動く: PWA）
     GitHub Pages  https://<user>.github.io/juggler_simulator/
```

- サーバーとの通信は静的ファイルの取得だけ。入力値は外部に送らない。

## 2. 画面一覧

画面上部のタブで2つのモードを切り替える。補助情報はシート（下から出るパネル）で出す。

- **かんたん入力**: データカウンタの値を入れて、すぐ結果を見る（UC-1, UC-3）。1画面で縦スクロール。
- **実戦モード**: 打ちながらタップで数え、推定の推移を見る（UC-2, UC-4）。片手・短時間の操作に特化。

| ID | 画面・領域 | 内容 |
|---|---|---|
| SC-01 | ヘッダー | アプリ名、機種選択、台メモ（Phase 2） |
| SC-02 | 入力エリア | 台データ（総回転数・BIG・REG）、遊技区間（回転数・ぶどう）、REG内訳（Phase 2） |
| SC-03 | 結果サマリー | 設定別事後確率の棒グラフ、設定4以上などの確率、機械割の加重平均（参考）、前提表示 |
| SC-04 | 分布グラフ | 指標タブ（BIG / REG / 合算 / ぶどう）、各設定の分布曲線＋実測値の縦線 |
| SC-05 | 比較表 | 実測値と各設定の確率（1/○○）の表 |
| SC-06 | 機種情報シート | 設定別スペック表、出典リンク、データ版、データ種別（公表値/解析値/実戦値） |
| SC-07 | 設定シート | 事前分布のプリセット選択（標準 / 高設定やや多め / 均等。各プリセットの6つの値と「店の実績に基づく値ではなく、Web の情報を参考にした想定」である旨も表示）、ぶどうを計算に使うかの ON/OFF、事前分布の手入力（Phase 2）、REG内訳の ON/OFF（Phase 2）、全データ消去 |
| SC-08 | 注意・ヘルプシート | 免責、見方の説明、ホール規則の案内、ぶどうの数え方 |
| SC-09 | 実戦モード: カウンター画面 | 打ち始めの記録、ぶどう・BIG・REG の +1 ボタン、戻す、総回転数の更新、事後確率の要約 |
| SC-10 | 推移グラフ | スナップショットごとの事後確率の推移と集中度（実戦モードの下部。終了した実戦記録を開いたときにも表示） |

## 4. 入力項目

| 項目ID | 名称 | 型 | 必須 | 範囲 | 既定値 | 備考 |
|---|---|---|---|---|---|---|
| IN-01 | 機種 | 選択 | ○ | 登録済み機種 | 前回値 / マイジャグラーV | |
| IN-02 | 総回転数 | 整数 | ○ | 0〜20,000 | 空 | 通常時G数（Q-02） |
| IN-03 | BIG回数 | 整数 | ○ | 0〜IN-02 | 0 | |
| IN-04 | REG回数 | 整数 | ○ | 0〜IN-02 | 0 | |
| IN-05 | 遊技区間 回転数 | 整数 | | 0〜IN-02 | 空 | 空ならぶどうは使わない |
| IN-06 | ぶどう回数 | 整数 | | 0〜IN-05 | 空 | |
| IN-07 | 単独REG | 整数 | | 0〜IN-04 | 空 | Phase 2 |
| IN-08 | チェリー重複REG | 整数 | | 0〜IN-04 | 空 | Phase 2。不明分 = IN-04 − IN-07 − IN-08 |
| IN-09 | 事前分布 | 選択/数値 | | 合計 100% | 均等 | Phase 2（Q-04） |
| IN-10 | 台メモ | 文字列 | | 20文字 | 空 | Phase 2 |

- すべての数値欄は `inputmode="numeric"`。全角数字は半角に直して受け付ける。
- 空欄の総回転数のときは結果を出さず「総回転数を入れてください」と表示する。
- **空欄と 0 は意味が違う**。BIG・REG の空欄は 0 回として扱う（データカウンタに必ず出る値のため）。遊技区間の回転数・ぶどう回数は、空欄=未計測、0=数えて0回。

| 遊技区間 回転数 | ぶどう回数 | 扱い |
|---|---|---|
| 空欄 | 空欄 | ぶどう未計測。ぶどうは計算に使わない |
| 入力あり | 入力あり（0 を含む） | ぶどうを計算に使う（ON のとき） |
| 入力あり | 空欄 | V-09（ぶどうは使わない旨を表示） |
| 空欄 | 入力あり | V-09（同上） |

## 5. 入力チェックとメッセージ

| ID | 条件 | 表示 | 結果の扱い |
|---|---|---|---|
| V-01 | 数値でない / 負の数 / 小数 | 「0以上の整数で入力してください」 | 更新しない |
| V-02 | BIG + REG > 総回転数 | 「BIGとREGの合計が総回転数を超えています」 | 更新しない |
| V-03 | 遊技区間 > 総回転数 | 「遊技区間が総回転数を超えています」 | 更新しない |
| V-04 | ぶどう > 遊技区間の回転数、または ぶどう > 総回転数 − BIG − REG | 「ぶどう回数が多すぎます（ボーナス以外のゲーム数を超えています）」 | 更新しない |
| V-05 | 単独REG + 重複REG > REG | 「REG内訳の合計がREG回数を超えています」 | 更新しない |
| V-06 | 総回転数 > 12,000 | 「1日の回転数としては多すぎます。前日分を足していませんか？」 | 警告のみ、計算する |
| V-07 | ぶどう回数が、どの設定で考えても起こりにくい（全設定で、ぶどうタブの分布の下側 0.1% 未満 または 上側 0.1% 未満） | 「数え間違い、数え方の違い、または機種データとの不一致の可能性があります」 | 警告のみ、計算する |
| V-08 | 総回転数 < 1,000 | 「まだ判断材料が少ないです」（FR-28） | 警告のみ、計算する |
| V-09 | 遊技区間の回転数とぶどう回数の片方だけ入力 | 「ぶどうは両方入れると計算に使います」 | 注意のみ、ぶどうなしで計算する |

- エラーのときは、直前の正しい結果を薄く表示し「入力エラーのため未更新」と出す（結果が消えてレイアウトが動くのを防ぐ）。ただし機種・データ版・事前分布・ぶどう ON/OFF のどれかが変わった後は、前の結果は出さない。

### 6.1 結果サマリー（SC-03）

| 項目 | 表示形式 | 内容 |

| 設定別事後確率 | 横棒＋％（小数1桁） | 合計100%。0.1%未満は「<0.1%」 |
| 設定4以上 / 5以上 / 6 | ％（小数1桁） | |
| 機械割（加重平均） | ％（小数1桁）＋「参考」 | Σ 事後確率 × 設定別の公表機械割。機械割の前提（例: 市場調査値）と「この先の収支を示すものではありません」を注記 |

| 事前分布 | テキスト＋[変更] | 選んでいるプリセット名。既定以外を選んでいるときは強調表示。下に小さく「比較: 事前が均等なら 設定4以上 ○%・設定6 ○%」（FR-17b。均等が正しいという意味ではない） |
| 注意 | テキスト | V-06〜V-09、事前分布の注意（「店の設定の入れ方で結果は大きく変わります。表示は低設定中心の店を想定した目安です」） |

### 6.2 分布グラフ（SC-04）

FR-24 の「正規分布のようなもの」は、次のように定義する。

> **ある設定だと仮定したとき、今の回転数でその指標が何回出るかの確率分布**（二項分布）。実測回数がどの設定の山に近いかを見る図。

| 項目 | 仕様 |
|---|---|
| 横軸 | 回数（例: BIG 回数）。補助目盛として「1/○○」換算を下に表示（例: 12回 → 1/250。0回は換算なし） |
| 縦軸 | その回数になる確率 |
| 曲線 | 設定1〜6の6本。各設定の確率を点で計算し、線で結ぶ。期待回数が 5 回未満のときは棒で描く |
| 実測値 | 縦の太線と「実測 12回」のラベル |
| 表示範囲 | 全設定の分布の 0.1%〜99.9% 点に、実測値を加えた範囲（実測値は必ず表示範囲に入る） |
| 指標タブ | BIG（総回転数で計算）/ REG / 合算 / ぶどう（遊技区間で計算。台の BIG・REG 回数を踏まえた分布。未計測・OFF ならタブを無効化） |
| 回転数 0 | グラフを出さず「回転数を入れると表示されます」 |
| 切り替え | 全設定表示 / 1設定だけ強調（他は薄く） |
| 凡例 | 色＋線種＋「設1〜設6」のラベルを曲線の山頂付近に直接表示（色覚多様性への配慮） |
| タップ | 曲線上をタップすると「設定4: 12回になる確率 10.2%、1/250」をツールチップで表示 |
| 注記 | 「この図は各設定での“出方のばらつき”です。設定の確率ではありません」 |

- 釣鐘形の幅は回転数が増えるほど相対的に狭くなる。これにより「回すほど判別しやすい」ことが視覚的に分かる。
- 実測値の縦線と各曲線の交点の高さは「その指標だけを見たときの、各設定での出やすさ」を表す。事後確率は BIG・REG・ぶどうを**まとめて**計算するため、1つのタブの交点の高さの比とは一致しない。ヘルプでは「どの設定の山に近いか」の目安として説明し、事後確率と同じものとは書かない。

### 6.3 比較表（SC-05）

| 行 | 実測 | 設定1〜6 |
|---|---|---|
| BIG | 1/(総回転数/BIG) | 機種データ |
| REG | 同上 | 同上 |
| 合算 | 同上 | 同上 |
| ぶどう | 1/(遊技区間/ぶどう) | 同上（解析値マーク付き） |

- 回数 0 の場合は「—」。（「実測値に最も近い設定」の強調はしない。最も確率が高い設定と誤解されやすいため）
- 横スクロールで設定1〜6を表示する（360px で 3 設定分見える程度）。

### 6.4 機種情報シート（SC-06）

- 設定別スペック表（BIG・REG・合算・機械割・ぶどう・REG内訳）
- 各値のデータ種別バッジ: 「公表値」「解析値」「実戦値」と、数え方の条件（ぶどうなど）
- 出典名・URL・参照日、データ版（更新日）

## 7. 状態の保存

| データ | 保存先 | 保存のタイミング | 消去 |
|---|---|---|---|
| 入力値（機種ごと）と最終更新日時 | localStorage | 入力のたびにすぐ。画面を離れるとき（pagehide）も | リセットボタン / 設定シートの全消去 |
| 選択中の機種・表示設定 | localStorage | 変更時 | 同上 |
| 複数台の保存（Phase 2） | localStorage | 保存ボタン | 個別削除 |

- localStorage が使えない環境（プライベートブラウズ等）でも、保存しないだけで動作する。保存に失敗したら一度だけ「この端末では入力を保存できません」と表示する。
- 最終更新日が今日でない入力を開いたときは「前回（○月○日）の入力です。リセットしますか？」と表示する（当日分のみの前提 C-02 を守るため）。
- 保存データにはスキーマのバージョン番号を付け、形式が変わったときは移行または破棄する。

## 11. 実戦モード（SC-09, SC-10）

### 11.1 流れ

```
[打ち始める] ─► カウンター画面 ─(タップで数える)─► [総回転数を更新] ─► 推定・推移を更新
      ▲               │                                    │
      │               └──────────── 繰り返し ◄──────────────┘
  打ち始めの              [打ち終わる] ─► 記録として保存（振り返り UC-3 に使う）
  カウンタ値を入れる
```

1. **打ち始め**: 台のデータカウンタの値（総回転数・BIG・REG）を入れて [打ち始める]。空き台なら 0 のまま。
2. **数える**: ぶどう・BIG・REG が出たらボタンを押す。BIG・REG のボタンは台全体の回数と、自分の区間の回数の両方を +1 する。
3. **総回転数の更新**: ときどき（ボーナス後や、ひと区切りごと）カウンタの総回転数を入れる。この時点の値一式を**スナップショット**として記録し、推定と推移グラフを更新する。
4. **打ち終わり**: [打ち終わる] で記録を保存し、かんたん入力の画面で振り返れるようにする。

### 11.2 カウンター画面のレイアウト

```
┌────────────────────────────────┐
│ 実戦 マイジャグラーV  [推移][≡]   │
│ 総回転数 3,250G（12分前に更新）    │
│ BIG 13  REG 12  ぶどう 302         │
│ 区間 1,250G  ぶどう 1/5.71(前回時点)│
├────────────────────────────────┤
│ 設1▇ 設2▇ 設3▇▇ 設4▇▇▇ 設5▇▇▇ 設6▇▇│ ← 前回更新時点の事後確率
│ 設定4以上 64%   集中度 23%          │
├────────────────────────────────┤
│                                    │
│          ぶ ど う  +1              │ ← 画面の約半分。押すと振動（対応端末）
│             302                    │
│                                    │
├─────────────────┬──────────────┤
│   BIG +1        │   REG +1      │
├─────────────────┴──────────────┤
│ [↶ 戻す]        [総回転数を更新]    │
└────────────────────────────────┘
```

- ボタンを押すたびに件数が変わるのがすぐ分かるよう、数字を大きく出す。誤タップ対策として [↶ 戻す] で直前の操作を取り消せる（直近 200 操作まで）。
- 事後確率は**総回転数を更新したときだけ**計算し直す。ぶどうだけ増えて回転数が古いままだと、ぶどう確率が実際より良く見えてしまうため。
- 前回の更新からぶどうが 30 回以上増えたら（約 170G 分）、「総回転数を更新してください」と表示する。
- 画面が消えないよう Wake Lock を使う（対応端末のみ。電池を使う旨をヘルプに書く）。

### 11.3 総回転数の更新ダイアログ

| 項目 | 内容 |
|---|---|
| 総回転数 | 数字キーボード。前回の値以上であること（V-10） |
| BIG / REG | タップで数えた値を初期値に表示し、カウンタの表示と違えば直せる |
| ぶどう（区間） | タップで数えた値を初期値に表示し、数え間違いがあれば直せる |
| チェック | 区間の回転数（現在 − 打ち始め）より、区間のボーナス回数 + ぶどう回数が多いとエラー（V-12） |
| 同じ総回転数 | 前回と同じ総回転数で確定した場合は、最新の点を置き換える（点を増やさない） |
| ダイアログ中 | 開いている間はカウンターボタンを押せない |
| 回数を減らす | BIG・REG・ぶどうを減らす訂正は、ダイアログ内に警告を出してから確定する。前の点より回数が減った点は、推移グラフで「訂正を含む点」として注記する（誤タップの取り消しは [↶ 戻す] で行う） |
| 打ち始めと同じ総回転数 | エラー（V-10）。回した後の総回転数を入れてもらう |
| 機種データの版が変わった | 再開時に、カウンターを止めて「新しいデータで続ける / 終了して履歴に残す」を選んでもらう |

### 11.4 推移グラフ（SC-10）

| 項目 | 仕様 |
|---|---|
| 横軸 | 総回転数（スナップショットの時点） |
| 縦軸 | 事後確率（%）。設定1〜6の **100% 積み上げ面グラフ**（既定）と、6本の折れ線の切り替え |
| 最初の点 | 打ち始めの時点（打ち始めのカウンタ値だけで計算した推定） |
| 集中度 | 下段に小さな折れ線で表示。0% = 6設定に均等に散らばっている、100% = 1つの設定に集まっている |
| 注記 | 「集中度は推定がどれだけ1つに集まったかで、正しい設定に近づいたことや当たりやすさを示すものではありません。下がることもあります」 |
| タップ | 各点で「3,250G: 設定4以上 64%、ぶどう 1/5.71、BIG 13 / REG 12」 |

- データが増えるにつれて積み上げの帯が寄っていく様子で、推定が絞り込まれていく過程を見せる。ボーナスの偏りで推定が逆戻りし、集中度が下がることもあるが、それもそのまま見せる。
- 機種データや計算方法が更新された後に過去の記録を開いたときは、記録当時の結果を表示し、「今の条件で再計算」を押すと別の線で重ねて表示する。

### 11.5 保存と再開

- タップ・総回転数の更新のたびに端末内に保存する。ブラウザを閉じても、開き直すと実戦モードの続きから再開できる（A-16）。
- 打ち始めの日付が今日でない実戦記録を開いたときは「前回（○月○日）の実戦です。終了しますか？」と表示する。
- 終了した記録は「履歴」に残る（端末内、最大 30 件。古いものから消す）。

### 11.6 追加の入力チェック

| ID | 条件 | 表示 | 結果の扱い |
|---|---|---|---|
| V-10 | 総回転数が前回の更新より小さい / 打ち始めより小さい | 「総回転数が前回より減っています」 | 更新しない |
| V-11 | BIG・REG が打ち始めの値より小さい | 「打ち始めの回数より少なくなっています」 | 更新しない |
| V-12 | 区間のボーナス回数 + ぶどう回数 > 区間の回転数 | 「区間の回転数に対して回数が多すぎます」 | 更新しない |
